# Dados embutidos

`common-passwords.txt`: senhas comuns e vazadas com 12 caracteres ou mais, em minúsculas, usadas para recusar senhas fracas sem consultar serviços externos. Geradas a partir de duas listas do [SecLists](https://github.com/danielmiessler/SecLists) (licença MIT): `Passwords/Common-Credentials/100k-most-used-passwords-NCSC.txt` e `Pwdb_top-1000000.txt`.
