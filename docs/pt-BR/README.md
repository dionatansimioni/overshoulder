# Documentação do Overshoulder

[English](../README.md) · Português

Compartilhamento de tela self-hosted, direto no navegador, com criptografia de ponta a ponta. Esta documentação explica como instalar, configurar e usar o servidor.

## Para quem instala e administra

- [Instalação](install.md): requisitos, subir com Docker, primeiro acesso, firewall, atualizar e fazer backup.
- [Configuração](configuration.md): variáveis do servidor e cada seção do painel `/admin`.
- [Atrás de outro proxy](proxy.md): Coolify, Dokploy, EasyPanel, Nginx, Caddy ou Traefik cuidando do HTTPS.
- [Contas e usuários](accounts.md): administrador, transmissores, convites, aprovação, 2FA, login da empresa e recuperação de senha.
- [Solução de problemas](troubleshooting.md): certificado, portas, vídeo que não chega, áudio no Linux, gravação.

## Para quem transmite

- [Salas](rooms.md): tipos de sala, convites, sala de espera, sala privada, salas fixas, moderação e gravação.
- [Transmitir](broadcasting.md): compartilhar a tela, áudio do jogo, câmera, qualidade, avisos de rede e celular.

## Para quem assiste

Não precisa de conta nem de instalação: basta abrir o link recebido, digitar um nome e entrar. Nos ajustes da sala dá para escolher a qualidade que você recebe. No celular, veja a página `/mobile` do próprio servidor.
